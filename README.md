make.fun entry for the [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty — the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

## The entry

> WARNING: This human runs on caffeine and spite, overheats in meetings, and will shut down without warning if asked to hop on a quick call.

## How it works

Run `python3 main.py`. It checks the entry against the bounty gate — UTF-8 text, 1 to 160 characters, not only white space, a single line, and starting with `WARNING:` — then writes it to `/output/entry.txt`. The program uses only the Python standard library and makes no network calls.
